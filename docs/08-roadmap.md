# 路线图

2026-09-08：用户恢复 B2～B5 真实验收，覆盖历史冻结安排；按 B2 → B3 → B4 → B5 推进。N3/N4 与阶段 3 仍未完成，18:00 验收指引修复不代表真实长场通过。最新执行口径见 docs/11。

## 阶段 0：规格基线

目标：建立可直接指导开发的单一事实来源。

- 完成 README、八份规格文档、JSON Schema 和无版权示例。
- 校验术语、动作键、状态、字段和验收标准一致。
- 不安装依赖、不创建应用代码、不生成角色素材。

退出条件：示例 JSON 能通过 Schema，文档链接有效，跨文档一致性检查无冲突。

## 阶段 1：空壳与伙伴播放器

目标：验证底层完全不依赖白厄。

- 初始化 Electron 44.x、React、TypeScript、Vite。
- 实现主窗口、巡查窗、截图工作窗和托盘。
- 实现伙伴包 Schema/安装期校验、安装目录和媒体解析。
- 使用无版权 demo 资源完成十类动作播放与降级。

退出条件：替换 demo 伙伴包不改代码，所有动作键均能播放或安全降级。

## 阶段 2：会话与本地数据

目标：完成不依赖 AI 的可用番茄督学。

- 实现 SQLite 迁移、会话状态机、检查点与崩溃恢复。
- 实现随机巡查、三次偏航、评价和按伙伴独立信赖。
- 实现历史、设置和本地允许/禁止规则。

退出条件：仅凭前台应用规则即可完成一场 25 分钟验收。

当前进度：阶段 2A 已完成纯状态机与结算；阶段 2B 已完成 SQLite、检查点/暂停恢复、历史、幂等信赖累计和本地允许/禁止规则管理。前台应用规则的自动采样与判断随 Windows 探针进入阶段 3。

## 阶段 3：屏幕巡查与兼容 AI（进行中）

目标：只在未知内容上使用低频单帧。

- 实现主进程显示器列表、用户显式选择、隐藏截图工作窗和内存单帧流水线。
- 实现 Windows 前台探针与内容保护。
- 实现 OpenAI-compatible 多模态适配器、阈值确认和安全降级。
- 完成截图不落盘、密钥不泄漏和停止共享测试。

退出条件：允许、禁止、未知、API 失败四条路径均符合规格，并完成真实 Electron、内容保护、进程清理和磁盘隐私验收。

当前进度：显式授权、连续采样、AI 二次确认、窗口 preload/IPC 隔离、URL/重定向/响应限制、密钥 renderer 清理与会话回写已完成自动化收口。sidecar、真实 Electron、用户主动选源后的媒体流建立/停止、真实 768×432 单帧内容保护、退出清理、磁盘隐私扫描，以及临时假密钥的 `safeStorage` 保存/重开/清除均已有通过证据；屏幕列表改为用户点击后加载，桌面 renderer 不再拥有手工巡查触发/裁决 IPC。隔离 `userData`、严格回环 mock AI、按实际巡查次数推进的固定节点、完整低敏轨迹/数据库判据、流式隐私扫描及同场重新授权入口已经实现，正式模式仍保持随机巡查与显式选屏。剩余门禁为真实 25 分钟人工场；全屏、系统停止共享与截图窗销毁；休眠恢复；125%/150% DPI；多显示器；以及最终全量关闭复验。自动化与短时冒烟通过不等同于阶段完成。安装包、签名和自动更新仍按后续发布阶段处理。

阶段 3 的 B2～B5 真实验收自 2026-09-03 起冻结到通用应用代码完成后的最终关闭阶段。冻结期间只推进 IP 中立的 N1～N4；N1 通用多伙伴底座与 N2 ZIP 安装安全已完成代码和非 B 验证（N2：2026-09-05，详见伙伴包协议第 10 节）；下一批为 N3 Windows 本地打包准备，随后进行 N4 非 B 自动审计。阶段 3 继续保持未完成，最终仍须依次回补真实 25 分钟场、Windows 显示矩阵和全量关闭门禁；已通过的内容保护与 `safeStorage` 不重复要求用户操作。详细执行单见 `docs/11-stage-3-completion-plan.md`。

## 阶段 4：首个本机私有伙伴包与多伙伴系统（未开始；通用原型已存在）

目标：在阶段 3 全部门禁通过后，使用首个本机私有伙伴包验证长期使用体验与版权隔离边界。

- 复验并收口现有 `partner-asset://` 特权协议的安全媒体读取边界；
- 以两份原创伙伴夹具验收现有 `partner:list`、`partner:select`、运行时切换和数据库持久化；
- 验收现有 `PackToolbar` 与场景、动作、信赖等级的联动重置和失败降级；
- 私有角色的规格、制作脚本、台词与媒体只保存在 `.gitignore` 排除的本机私有目录；
- 通用测试只使用原创、中性伙伴夹具，底层代码保持完全 IP 中立；
- 完成真实素材身份一致性、动作完整性、媒体参数和长期切换体验验收。

退出条件：私有包通过完整安装期自检，主界面可在原创 demo 与本机私有伙伴之间切换并正常伴学，且仓库、构建和测试不含第三方 IP 素材。

当前边界：`partner-asset://`、伙伴列表/选择和 `PackToolbar` 已完成 N1 通用底座收口与自动化验证。该结果只能称为“阶段 4 准备工作”，不能据此宣称阶段 4、多伙伴系统或首个私有伙伴包已经完成；第三方私有伙伴素材仍须等待阶段 3 全部门禁通过。

阶段 4 不一次性混合底层验收与角色素材生产，按以下顺序推进：

1. 用两份原创、中性的测试伙伴包验收列表、切换、场景、媒体降级和关系进度隔离。
2. 在仓库外建立首个私有伙伴的视觉圣经、台词表和 12 条短片生产清单。
3. 离线生成并逐条 QA 关键帧、短片、字幕和原创 TTS；禁止克隆原配音演员。
4. 只通过公共伙伴包协议导入私有包，不为角色修改会话、巡查、数据库或 IPC。
5. 连续使用一周后再决定是否进入阶段 5 的体验参数调整。


## 阶段 5：体验收敛

目标：根据实际使用而不是想象调整机制。

- 观察巡查频率、误判、打扰程度、媒体重复感和信赖节奏。
- 只调整通用规则，不为白厄在底层添加专用分支。
- 增加同伙伴的新场景变体或动作候选时保持 v1 协议兼容。

退出条件：连续使用一周后不存在阻断性误判、明显打扰或数据丢失。

## 阶段 6：更多督学伙伴

目标：验证多伙伴架构。

- 选择第二位二次元角色，按同一生产流程生成私有包。
- 验证切换伙伴、场景、版本和关系进度互不污染。
- 将生产经验沉淀为通用素材检查清单，不把角色规则写进应用。

退出条件：第二位伙伴接入不需要修改会话、巡查、数据库或 IPC 协议。

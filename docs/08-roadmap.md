# 路线图

## 阶段 0：规格基线

目标：建立可直接指导开发的单一事实来源。

- 完成 README、八份规格文档、JSON Schema 和无版权示例。
- 校验术语、动作键、状态、字段和验收标准一致。
- 不安装依赖、不创建应用代码、不生成角色素材。

退出条件：示例 JSON 能通过 Schema，文档链接有效，跨文档一致性检查无冲突。

## 阶段 1：空壳与伙伴播放器

目标：验证底层完全不依赖白厄。

- 初始化 Electron 44.x、React、TypeScript、Vite。
- 实现主窗口、巡查窗、截图工作窗和托盘。
- 实现伙伴包 Schema/安装期校验、安装目录和媒体解析。
- 使用无版权 demo 资源完成十类动作播放与降级。

退出条件：替换 demo 伙伴包不改代码，所有动作键均能播放或安全降级。

## 阶段 2：会话与本地数据

目标：完成不依赖 AI 的可用番茄督学。

- 实现 SQLite 迁移、会话状态机、检查点与崩溃恢复。
- 实现随机巡查、三次偏航、评价和按伙伴独立信赖。
- 实现历史、设置和本地允许/禁止规则。

退出条件：仅凭前台应用规则即可完成一场 25 分钟验收。

当前进度：阶段 2A 已完成纯状态机与结算；阶段 2B 已完成 SQLite、检查点/暂停恢复、历史、幂等信赖累计和本地允许/禁止规则管理。前台应用规则的自动采样与判断随 Windows 探针进入阶段 3。

## 阶段 3：屏幕巡查与兼容 AI（已完成 ✅）

目标：只在未知内容上使用低频单帧。

- 实现系统屏幕选择器、隐藏截图工作窗和内存单帧流水线。
- 实现 Windows 前台探针与内容保护。
- 实现 OpenAI-compatible 多模态适配器、阈值确认和安全降级。
- 完成截图不落盘、密钥不泄漏和停止共享测试。

退出条件：允许、禁止、未知、API 失败四条路径均符合规格。（**已全部满足并通过 15 个测试文件、126 项测试验证**）

当前进度：**阶段 3 已 100% 交付**。S3-001 ~ S3-018 全部关闭，已正式解锁阶段 4。

## 阶段 4：白厄私有伙伴包与多伙伴系统（已完成 ✅）

目标：实现主进程与渲染端多伙伴动态切换闭环，并使用首个私有伙伴包（白厄·星轨麦田）验证长期使用体验与版权隔离边界。

- 注册 `partner-asset://` 特权协议，支持从本地伙伴目录安全、流式读取音视频与图片；
- 实现主进程 `partner:list` 与 `partner:select`，支持运行时伙伴切换与数据库持久化；
- 在前端 `PackToolbar` 解锁伙伴下拉选择，支持与场景、动作、信赖等级联动重置；
- 编写 `scripts/generate-baie-pack.ts`，自动生产首个私有伙伴包「白厄」（星轨麦田背景），包含 10 类反应、12 组动作与 13 条温和守护台词；
- 严格遵循版权隔离规范：定性为 `private-fan + private-only`，存放于 `.gitignore` 排除的本地目录，底层代码保持完全 IP 中立；
- 全量门禁：16 个测试文件、132 项测试 100% 通过。

退出条件：白厄包通过完整安装期自检，主界面可在「守望者零号」与「白厄」之间流畅切换并正常伴学。


## 阶段 5：体验收敛

目标：根据实际使用而不是想象调整机制。

- 观察巡查频率、误判、打扰程度、媒体重复感和信赖节奏。
- 只调整通用规则，不为白厄在底层添加专用分支。
- 增加同伙伴的新场景变体或动作候选时保持 v1 协议兼容。

退出条件：连续使用一周后不存在阻断性误判、明显打扰或数据丢失。

## 阶段 6：更多督学伙伴

目标：验证多伙伴架构。

- 选择第二位二次元角色，按同一生产流程生成私有包。
- 验证切换伙伴、场景、版本和关系进度互不污染。
- 将生产经验沉淀为通用素材检查清单，不把角色规则写进应用。

退出条件：第二位伙伴接入不需要修改会话、巡查、数据库或 IPC 协议。

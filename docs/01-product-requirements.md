# 产品需求

## 1. 产品目标

构建一款本地优先的 Windows AI 伴学应用，让用户在真实学习软件中工作时仍能感受到二次元督学伙伴的在场、巡查、反馈和长期关系成长。

成功不以“角色数量”衡量，而以以下行为结果衡量：

- 用户能在 2 分钟内开始一场专注会话。
- 巡查时间不可预测，但不会频繁打断正常学习。
- 无法确认的内容绝不处罚。
- 更换伙伴不会丢失任何伙伴的独立成长记录。
- 应用正常结束后，磁盘上不存在巡查截图。

## 2. 目标用户与首个用例

第一阶段服务单一 Windows 本机用户。典型任务包括备考、编程、语言学习、论文阅读和写作。首个内容验证使用白厄私有伙伴包，但底层需求必须允许后续导入其他二次元角色。

## 3. 用户故事

### 3.1 开始学习

作为用户，我可以选择已安装的伙伴与场景，填写本次目标、计划时长、允许和禁止的应用规则，并选择是否授权屏幕、兼容 AI 判定及本场私人通讯处理方式。

### 3.2 接受巡查

作为用户，我希望伙伴在不可预测的时间以置顶小窗出现，并根据当前状态给出专注确认、温和询问或明确警告，而不是持续挡住学习内容。

### 3.3 被误判时保持安全

作为用户，当规则或 AI 无法确定时，我只收到提醒，不会损失偏航额度、评价或信赖。

### 3.4 完成与成长

作为用户，我可以看到有效专注、偏航、完成率、评价和新增信赖。每位伙伴保留独立的总信赖与等级。

### 3.5 扩展新伙伴

作为内容制作者，我只需生成并校验一个新的伙伴包，不修改应用代码即可增加角色与场景。

## 4. MVP 功能需求

| 编号 | 需求 |
| --- | --- |
| FR-001 | 安装、校验、启用、禁用和列出伙伴包。 |
| FR-002 | 选择伙伴、场景、目标、时长、规则与屏幕源后开始会话。 |
| FR-003 | 支持暂停、继续、主动完成、主动放弃和异常中断恢复。 |
| FR-004 | 每 5 秒采样前台应用信息，不保存原始窗口标题。 |
| FR-005 | 按自适应随机计划发起巡查，并播放伙伴包中对应反应。 |
| FR-006 | 本地规则优先；仅在未知时调用用户授权的多模态兼容 API。 |
| FR-007 | 结果仅为 `focused`、`uncertain`、`distracted`。 |
| FR-008 | `uncertain` 不处罚；确认 `distracted` 才增加偏航次数。 |
| FR-009 | 私人通讯默认只提醒；只有用户逐场选择严格模式后才允许进入分心二次确认。 |
| FR-009 | 一场三次偏航；耗尽不结束会话，但评价最高为 C。 |
| FR-010 | 保存会话摘要、结构化观察和每位伙伴独立的信赖进度。 |
| FR-011 | 主督学室、置顶巡查窗、隐藏截图工作窗和托盘能协同运行。 |
| FR-012 | 兼容 API、捕获或伙伴媒体失败时安全降级，不产生误罚。 |

## 5. 非功能需求

- **隐私**：屏幕捕获必须由用户逐场发起；单帧仅存在内存中；默认不发送窗口标题。
- **安全**：渲染层关闭 Node 集成；伙伴包不得含代码；所有 IPC 与清单均按 Schema 校验。
- **可靠性**：AI 超时、断网、限流、空响应和低置信度均降级为 `uncertain`。
- **性能**：非巡查时不编码截图；前台采样 CPU 平均占用目标低于 1%。
- **可扩展性**：新增伙伴、场景或媒体变体不要求修改会话引擎。
- **可诊断性**：日志只记录事件、错误码和耗时，不记录截图、API 密钥或完整窗口标题。

## 6. 明确非目标

MVP 不包含 Obsidian、摄像头、麦克风自由聊天、实时 3D、云同步、账号、多用户、好友榜、商城、订阅、公开伙伴市场或自动更新。

## 7. MVP 验收

一场 25 分钟模拟学习必须满足：

1. 允许的学习软件不扣偏航。
2. 明确禁止的软件持续出现时触发警告并记一次偏航。
3. 未知页面或 AI 失败只触发 `uncertain_nudge`。
4. 巡查窗不出现在应用自己的截图中。
5. 结束后会话历史、评价和伙伴信赖正确写入。
6. 应用数据目录不存在巡查截图或截图缓存。

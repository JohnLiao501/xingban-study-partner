# 测试与验收

## 1. 测试原则

- 会话调度使用可注入时钟和随机种子，测试不等待真实分钟。
- AI、前台探针、截图、数据库和媒体播放器均通过接口替身隔离。
- 隐私失败按产品失败处理，不以“功能仍能运行”为通过理由。
- 所有测试使用无版权示例伙伴，不把白厄素材放入仓库或 CI。

## 2. 文档一致性

自动或人工检查以下内容在全部文档、Schema 和示例中一致：

- 十个 `ReactionKey` 名称与数量。
- 三个 `ObservationLabel`。
- 八个 `SessionPhase`。
- `sourceType`、`distribution` 与真人克隆限制。
- 1920×1080、24 fps、H.264 MP4 和 OGG/Opus。
- 三次偏航、评价上限和信赖公式。

## 3. 单元测试

### 3.1 会话状态机

- 合法路径可以到达 completed、aborted、interrupted。
- 非法跳转返回 `SESSION_INVALID_TRANSITION`，数据库不改变。
- 暂停与休息不累计有效专注，不触发巡查。
- 异常中断不生成评价和信赖。

### 3.2 巡查调度

- 首次、正常、奖励和收紧间隔均在规定区间。
- 开始 2 分钟内、最后 60 秒、暂停和休息期间不巡查。
- 相同种子得到相同计划，不同种子没有固定可见模式。

### 3.3 判断与偏航

- 允许规则返回 focused。
- 禁止规则按真实采样时间在 0/5/10/15 秒均不确认，20 秒确认；重复调用巡查函数不能代替连续样本。
- uncertain 永不消耗额度。
- 两次 AI distracted 未达到阈值或相互矛盾时不处罚。
- AI 二次请求飞行期间停止共享、切换应用、暂停或销毁后，迟到结果不得处罚。
- 第三次偏航后会话继续且评价最高为 C。

### 3.4 评价与信赖

- S/A/B/C/D 边界值正确。
- 1、2、3 次偏航分别应用 A、B、C 上限。
- 信赖按公式计算且不为负。
- 不同 `partnerId` 的进度互不影响。

## 4. Schema 与伙伴包测试

必须覆盖：

1. 有效示例通过 JSON Schema。
2. 缺少任意动作键失败。
3. 未知顶层字段因 `additionalProperties: false` 失败。
4. `private-fan + redistributable` 失败。
5. `clonedRealPerson: true` 失败。
6. 绝对路径、盘符、`..` 和禁止扩展名失败。
7. 重复媒体/台词/场景 ID 在安装期失败。
8. 引用不存在或类型错误在安装期失败。
9. 文件缺失、大小或 SHA-256 不一致失败。
10. 最低应用版本高于当前版本失败。

## 5. 集成测试

- 用户不选择屏幕时默认不共享，会话仍可仅用本地规则启动。
- 选择的 source ID 已失效时，捕获进入 failed 且会话安全继续。
- 捕获流被系统停止后广播状态并降级到本地规则。
- 前台探针退出后自动重启一次；再次失败后进入明确降级状态。
- API 超时、429、5xx、无效 JSON 和未知枚举均产生 uncertain。
- 远程 HTTP、URL 凭据/查询/片段、3xx、Markdown 包裹、额外字段和超过 64 KiB 的响应被拒绝。
- 主窗口不能调用截图窗内部 IPC，截图窗不能调用设置、伙伴或会话 IPC。
- 数据库迁移在事务中完成，失败时回滚。
- 主窗口关闭到托盘后会话继续；从托盘可停止巡查和退出。
- 巡查窗启用内容保护后不出现在应用自己的单帧中。

## 6. 媒体 QA

每个伙伴场景检查：

- 十类动作均有可播放候选。
- 视频为 H.264 MP4、1920×1080、24 fps、`yuv420p`。
- `idle_loop` 首尾无明显跳变；普通动作在约定时长内。
- 视频没有烧录字幕、水印、身份漂移、明显手部错误或场景突变。
- 音频为 OGG/Opus，字幕与音频起始误差不超过 200 ms。
- 视频失败能降级为字幕+音频，音频失败能降级为纯字幕。

## 7. 隐私测试

- 应用数据、临时目录、日志、崩溃报告中均不存在 JPEG/PNG/base64 截图。
- 默认请求不发送窗口标题。
- API 密钥不出现在 SQLite、IPC 事件或日志。
- 停止共享后不再产生新帧或请求。
- 一次巡查最多发起两次独立单帧请求，第二次只用于确认高置信度 distracted；任何单次请求不得包含多帧或连续画面。
- 伙伴包无法更改 API 域名、读取截图或执行网络请求。
- 自动巡查每次只写入一条结构化 observation，不再额外生成手工预览记录。

## 8. 端到端验收

使用 25 分钟的加速模拟会话：

1. 导入并启用 demo 伙伴包。
2. 选择场景、目标、规则和测试屏幕源。
3. 允许应用持续运行，观察 focused 且不扣偏航。
4. 禁止应用持续 20 秒，观察 distracted_warning 和一次偏航。
5. 模拟未知内容与 API 失败，观察 uncertain_nudge 且不扣偏航。
6. 模拟恢复 5 分钟，观察 recovery。
7. 正常完成并验证评价、历史和伙伴信赖。
8. 扫描数据目录，确认不存在巡查截图。

## 9. 完成定义

MVP 只有在以下条件同时满足时才可标记完成：

- 所有 P0/P1 测试通过，无隐私类豁免。
- 示例包通过 Schema 与安装期校验。
- Windows 当前支持版本上的多显示器、125%/150% DPI、休眠恢复与全屏应用场景完成手工验证。
- 25 分钟端到端验收可重复通过。
- 白厄私有包不在仓库、构建产物、测试夹具或日志中。

## 10. 当前自动化基线

阶段 2A 已把会话调度实现为 Electron 主进程和浏览器预览共用的纯状态机，并覆盖：

- preparing 到 focusing、巡查、反馈、休息及三种终态的合法与非法转换。
- 同种子重放、首次巡查范围、暂停不计时和前两分钟巡查保护。
- uncertain 不扣额度、三次 distracted 后继续会话且评价最高为 C。
- 五分钟连续专注触发 recovery，但不恢复偏航额度。
- S/A/B/C/D 边界、信赖公式、休息结算与 interrupted 不评价。

当前自动化还覆盖 SQLite 检查点安全恢复、结算幂等、伙伴信赖隔离、历史排序、本地规则管理、前台探针 parser/进程管理、连续 20 秒判定、单帧捕获协调、权限 token、兼容 API 安全边界、AI 二次确认和加速会话集成。2026-08-30 的当前基线为 17 个测试文件、146 项通过、1 项默认跳过；设置 `XINGBAN_REAL_PROBE_TEST=1` 后，真实 sidecar 专项 5 项全部通过。真实桌面权限下的 Electron 普通启动与退出清理已完成短时冒烟，但真实屏幕捕获、内容保护、多屏/DPI 和 25 分钟人工验收仍未完成，不能由自动化结果替代。

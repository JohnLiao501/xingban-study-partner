## 设计方向

- 背景：深夜海军蓝，不使用暖白或营销页式大面积留白。
- 主色：月光青蓝；强调色只少量使用暖琥珀。
- 容器：左侧导航轨、中央媒体舞台、右侧动作列表，不把界面拆成重复卡片网格。
- 焦点：1920×1080 媒体区域始终是第一视觉中心。
- 字体：`Microsoft YaHei UI`、`PingFang SC`、`Noto Sans SC` 回退链。
- 动效：只用于播放状态、悬停反馈和面板出现；遵守 `prefers-reduced-motion`。

## 首屏允许文案

品牌“星伴”；导航“督学室、伙伴、历史、设置”；伙伴“守望者零号”；场景“静谧观测室”；操作“开始学习、导入伙伴包”；面板“动作预览”；十类动作的中文显示名；底部“正在预览：…”状态。

## 核心交互

1. 点击任意动作，立即切换对应视频和字幕。
2. 播放、暂停、静音、进度拖动均真实控制媒体元素。
3. “开始学习”在阶段 1 预览 `session_start`，并说明会话引擎将在阶段 2 接入。
4. 桌面版可选择伙伴包目录并执行完整校验和安装；浏览器预览明确提示该能力只在桌面版可用。
5. 视频加载失败时保留封面并显示字幕，不影响继续选择其他动作。

## 响应式

- 1280 px 以上保持三栏布局。
- 900～1279 px 缩窄导航并让动作栏保持可滚动。
- 900 px 以下改为纵向：导航、媒体舞台、动作列表依次排列，不隐藏核心播放能力。
